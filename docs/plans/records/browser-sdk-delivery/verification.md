## Failures fixed and limits

- The first pure-2D draw exposed `inspectSceneResources` applying `instanceof`
  to the absent optional Mesh class. The shared diagnostic now checks whether
  that constructor exists; regression verifies 2D texture/render-target counts.
- Root had esbuild 0.27.1 while the prior dependency range installed 0.24.2;
  installed-vs-checkout output comparison correctly failed before upload.
  Pin 0.27.1 and reject a mismatching bundler. Repack/reinstall then matched all
  generated bytes. Older candidates are retained externally as failed evidence.
- Bundle profiles intentionally omit optional physics/Spine/glTF/etc modules.
  Having a public helper export is not proof of its optional native dependency.
- The existing hosting CSP permits only each game's own release directory.
  External HTML can use the fixed SDK URL; hosted games must package the same
  bytes under their own release. No server/CSP/permission change was performed.
- Examples use a managed runtime, shared library and scope disposal; inline
  provider checks cancellation and serves only the declared neutral logical ID.
  User asset loading still uses the existing provider lifecycle.
- Browser-global declarations reuse the public types. Existing vendor full
  declaration debt is unchanged. Passing these examples is not a consumer game
  Doctor, complete Prefab program or target-device acceptance.

Decision: implemented and verified for the documented desktop/hosting scope;
physical-device acceptance remains unavailable. The script/ZIP URLs are immutable;
rollback uses the previous explicit SDK pin, never overwrites an existing release.
