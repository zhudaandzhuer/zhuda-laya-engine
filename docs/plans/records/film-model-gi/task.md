# Agent task: film-model-gi

Status: Implemented within scope; desktop WebGL verified  
Owner: Engine/toolchain  
Last reviewed: 2026-11-11

## Source requirement

The user judged the procedural ancient-city film not realistic enough and
chose this route: an external modelling tool (Blender) is an asset factory
only; the engine stays the renderer and gains the missing capabilities. Two
gaps block it: film scenes cannot place glTF models, and they have no global
illumination (flat ambient only; point lights cast no shadows).

## Goal

A film scene can place self-contained GLB models by logical asset id and give
each a baked lightmap (Radiance HDR). The lightmap carries the scene's
diffuse global illumination (bounce light, soft shadows from every light) and
is drawn by Laya 3.4.2's native lightmap path.

## Invariants

- Native Laya only: models load through the existing `ZhudaModelLibrary`
  (glTF module); lightmaps use `Scene3D.lightmaps` and the renderer's
  `lightmapIndex`. No custom shader or second renderer.
- Asset ids are logical and go through an `AssetProvider`; a scene never
  carries a path or URL. The existing cache/lease lifecycle owns loaded
  models and lightmaps.
- Loading handles cancellation, timeout, failure and disposal; a stage that
  was cancelled or disposed never adds a late result.
- Scenes without model nodes mount and render exactly as before, through the
  same synchronous `mountZhudaFilmScene`.
- No model, texture or lightmap asset is added to this repository; fixtures
  are generated by the check script.

## Scope

### Engine

- `ZhudaFilmScene` node `model` (`asset`, `position`, `yawDeg`, `scale`,
  `lightmap`, `lightmapIntensity`), validated with paths.
- `decodeRadianceHdr`, `encodeZhudaLightmapRgbm` (pure) and the runtime
  lightmap texture.
- `ZhudaFilmAssets` (model library and lightmap cache over one provider) and
  `loadZhudaFilmScene` (async mount).
- Film host `--film-assets DIR`: serves the directory to the page as a
  `DirectoryAssetProvider`; the MCP tools list its files.
- Unit tests, a real-GPU check, docs and MCP descriptions.

### Consumer or adapter

- None. Blender scripts and the assets they produce live with the film,
  outside this repository.

## Non-goals

Real-time global illumination, reflection probes, shadows from point lights
in real time, animated models in film renders, lightmap baking inside the
engine, directional lightmaps.

## Acceptance checks

1. Validation reports every bad model field with a path; unknown asset ids
   are reported when the host lists its assets.
2. HDR decoding and RGBM encoding round-trip within the stated tolerance.
3. Real WebGL: a GLB placed by a scene is drawn; with a lightmap the lit
   regions follow the lightmap's UV1 layout and the unlit ones stay dark;
   a missing asset and a model without UV1 fail with a clear message.
4. 30 mount/unmount cycles leave no model instance and no growing cache.
5. `npm run verify`, lint, format, `verify:film` and `verify:film-look` pass.
