completion and 30 create/dispose cycles. The browser fixture additionally
checks missing IDs and nodes, stale evidence after a texture change, a shifted
text node, a same-sized wrong texture, and a manually created substitute with
no Prefab provenance. Every successful scene and preview report identifies the

## Limits and decision

- Mobile Safari, Android hardware, GPU vendor differences, context-loss
  recovery and production game assets remain unverified.
- The release supports static 2D hierarchies with declared image dependencies;
  3D, Spine and procedural effect previews remain follow-up work.
- Headless WebGL verifies draw behavior and resource lifecycle but is not a
  substitute for target-device performance or color calibration.

Decision: **Accepted** for the delivered P0 scope in engine version 1.1.0.
