# Agent task: film-animation

Status: Implemented within scope; desktop WebGL verified  
Owner: Engine/toolchain  
Last reviewed: 2026-11-11

## Source requirement

The user wants a story film in the town set: a character (their pig model,
rigged and animated in Blender) walks the streets carrying a lantern. Film
scenes place static models only; nothing moves except the camera.

## Goal

A film scene can play a named animation clip on a model, move a model along
keyed positions over the shot, and let a light follow a model, all as a pure
function of shot time so every frame is reproducible.

## Invariants

- Laya 3.4.2 only. Clips are sampled with the existing
  `ZhudaModelAnimationSampler` (absolute time, no state machine tick).
- Time comes from the capture's frame time; no wall clock, no timers.
- A scene without `animation`, `motion` or `follows` behaves exactly as
  before.
- Samplers are released with the stage.

## Scope

### Engine

- `model` nodes: `animation { clip, loop, speed, offsetSec }` and
  `motion` (keyed position and yaw).
- `light` nodes: `follows { node, offset }`.
- `sampleZhudaFilmMotion` (pure), `ZhudaFilmStage.setTime`, renderer and
  host `time` for previews, review shots and stills.
- Unit tests, a real-GPU check, docs, MCP descriptions.

### Consumer or adapter

- None. Rigging and clips are made outside the engine.

## Non-goals

Blending between clips, events, root motion from the clip, inverse
kinematics, animated look or material values, physics.

## Acceptance checks

1. Validation reports bad animation, motion and follows fields with paths;
   an unknown clip is refused at mount with the clips the model has.
2. `sampleZhudaFilmMotion` interpolates position and takes the short way
   around for yaw; it holds the first and last keys.
3. Real WebGL: a skinned, animated GLB generated by the check draws
   differently at two clip times and identically at the same time; a moving
   model is at the keyed place at a given time; a following light lights the
   ground beside the model after it has moved and turned.
4. `npm run verify`, lint, format and the film GPU checks pass.
