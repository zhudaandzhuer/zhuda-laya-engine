## Failure / recovery behavior

- Theme schema/contract/required ID/hash/size/budget failures are explicit.
  Current presentation survives failed preparation and corrupt bytes.
- Non-cooperative late byte/prepared results release after abort/timeout;
  newer requests win, borrowed source provider is never disposed by a theme.
  Unit tests cover 100 replacements and external abort/disposal.
- Result state starts locked until authoritative reconciliation. Duplicate,
  conflicting, older, gap, incomplete-prior and reused current round IDs have
  distinct handling. Store-write failure preserves the previous snapshot.
- A new coordinator restores saved cursor only after matching authoritative
  result; a newer authority result resets the cursor. Regression/conflict,
  malformed storage, failed recovery, timeout and cancellation remain locked.
- 1000 unit presentations retain one checkpoint. Browser recovery separately
  checks suspended input then reconciliation/unlock with a completed result.
  This is presentation recovery, not backend exactly-once settlement. No
  multi-tab storage CAS or customer backend authentication is claimed.

## Additional defect found during acceptance

The independent container test exposed Laya 3.4.2's delayed `updateCanvasSize`
from its separate callLater queue. It could overwrite a managed 640×360 canvas
with window-fit sizing after initialization. The version-specific adapter now
clears that exact queued callback before applying container dimensions; other
timers remain intact. Both unit regression and actual DPR1/2/3 replay pass.
The broader existing 2D/3D/input/resize browser fixture also passes.

## Limits and release decision

Physical iOS/Android, a low-end phone 60-minute session, GPU-driver memory,
Native AAB/IPA/signing and real customer Slot/backend failure matrix: **NOT RUN**.
The release must not be described as Accepted for those adoption conditions.

Theme v1 maps byte assets. Native streaming BGM continues to use the existing
stream provider/mixer. Consumer-specific decoded Spine/font/locale/layout
validation belongs in prepare; metadata alone does not certify those contents.

Skin Editor, AI configuration generation, domain Slot/Board kits and multi-game
Factory orchestration remain later roadmap work after a customer pilot.
