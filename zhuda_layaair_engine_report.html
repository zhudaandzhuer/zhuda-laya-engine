🤖 為什麼是「豬大的 Agent-Friendly 分支版本」？

針對 AI Coding Agent（Claude Code / Cursor / Windsurf / AGY / Codex）在無 GUI 終端環境開發 LayaAir 遊戲時的五大痛點，提供 Zero-IDE AST 自動類別反射、DAG 拓撲載入器、Graphics.setState 原型解毒、離線 .lh 像素與 ΔE00 色差校準 及 內建 11 工具 MCP Server。

引擎啟動與 Stage 初始化
Laya 3.4.2 採用非同步 Promise Laya.init(w, h)，且需在初始化前後掛載 Prototype Detox 與拓撲守衛。		 Laya.init(1280, 720, Laya.WebGL); Laya.MiniAdpter.init(); const { stage, rootScene } = await ZhudaEngine.boot({ width: 1280, height: 720, features: "all" });
3D 網格與材質建立
Laya 3.4.2 的 MeshSprite3D 建構子不再直接接收 Mesh，必須透過 meshFilter.sharedMesh 與 meshRenderer.sharedMaterial 指定以啟動動態合批。		 new Laya.MeshSprite3D(Laya.PrimitiveMesh.createBox(1, 1, 1)); const sp = new Laya.MeshSprite3D(); sp.meshFilter.sharedMesh = Zhuda3D.createPrimitiveMesh("box", { width: 1, height: 1, depth: 1 }); sp.meshRenderer.sharedMaterial = Zhuda3D.createMaterial({ albedoColor: [0.2, 0.5, 0.9, 1], shininess: 32 });
3D 平行光組件
Laya 3.4.2 已全面改為組件化 (Entity-Component)，燈光必須透過 Sprite3D.addComponent(Laya.DirectionLightCom) 掛載。		 const light = scene3D.addChild(new Laya.DirectionLight()); const { node, light } = Zhuda3D.createDirectionalLight(scene3D, { intensity: 1.3, rotationEuler: [-55, 35, 0] });
純代碼 2D 向量按鈕
Laya.Button 內部強依賴 AutoBitmap.setState，直接覆寫 graphics 在滑鼠懸停時會拋出 this._graphics.setState is not a function。		 const btn = new Laya.Button(); btn.graphics.drawRect(0, 0, 100, 40, "#336699"); const { root, label } = ZhudaUI.createVectorButton(parent, x, y, "按鈕文字", { width: 100, height: 40 }, onClick);
自定義 Script 組件註冊 (脫離 IDE)
脫離 IDE 後必須透過 @zhudaComponent 裝飾器與 @zhuda-laya/compiler 的 AST 掃描器自動注入 ClassUtils.regClass。		 export default class PlayerScript extends Laya.Script {} // 依賴 IDE 黑盒掃描 @zhudaComponent({ className: "PlayerScript", category: "3d" }) export class PlayerScript extends Laya.Script {}
3D 相機螢幕射線拾取
Laya 3.4.2 viewportPointToRay 為零 GC 設計，必須傳入預先配置的 Laya.Ray 實例作為輸出。		 camera.viewportPointToRay(new Laya.Vector2(x, y)); // 缺少 out Ray 參數 const ray = new Laya.Ray(new Laya.Vector3(), new Laya.Vector3()); camera.viewportPointToRay(new Laya.Vector2(screenX, screenY), ray);
動態轉靜態資產 (.lh) 與像素/色差 (ΔE00) 孤立校準
Laya 3.4.2 的 DrawRoundRectCmd 建構子預設 percent: true，必須透過 ZhudaAssetSerializer 顯式序列化 percent: false 並以 PixelCalibrationEngine 單步收斂至 0px 與 ΔE00=0。		 每次修改 2px UI 座標或粒子色號都重新啟動完整遊戲 Runtime 肉眼比對 const lh = ZhudaAssetSerializer.serializeNodeToHierarchy(node, { assetId: "assets/prefabs/MyCard.lh", targetSpec }); const report = PixelCalibrationEngine.calibrateAsset(lh); const converged = ZhudaAssetSerializer.applyCalibrationPatches(lh, report.autoFixPatches); const inst = ZhudaPrefab.instantiate(converged, parent);
